PRODUCT PREVIEW · USER DATA

Privacy starts with the recording controls.

TraceCue is a developer preview. This is a plain-language description of its current data behavior, not a claim of a completed security audit or a substitute for a final legal privacy policy.

What the extension captures

Only when you explicitly start recording an authorized browser tab, TraceCue may capture tab video, page interaction metadata, console error and warning messages, sanitized network response metadata, and environment information. Verbose console log, info and debug capture is opt-in. The system does not intentionally record typed field values, cookies, authorization headers, or raw request and response bodies.

Console logs and visible video can nevertheless expose private data. Automated redaction is best effort and must not be considered a guarantee.

Where your evidence is kept

The Chrome companion saves recordings and reports in browser-local extension storage. Studio examines imported reports and video locally. Deleting your browser profile or extension can erase that material; local browser storage is not an encrypted backup service. Team cloud synchronization is not available in this preview.

AI and third parties

Text queries and evidence search can be run without sending your video to a server. On-device AI uses the supported Chrome local model when available. If you explicitly approve Firebase cloud AI, reviewed text evidence is sent to Firebase AI Logic and its configured model provider. The separate video-question action sends a chosen video clip only after additional affirmative consent. No video is uploaded as part of ordinary local evidence search.

Sharing, permissions and retention

TraceCue does not automatically publish GitHub issues or upload your recordings. Reports and videos leave your browser only through deliberate export, approved cloud AI features, or a user-initiated handoff to an explicitly selected Studio origin. A local handoff transfers evidence between browser windows; it does not itself authorize cloud upload.

Do not use this development preview on banking portals, real customer accounts, production systems containing personal data, or other sensitive applications. Only record pages you have permission to test. Use the in-product deletion feature to remove local evidence when no longer needed.

Product updates and contact

This preview notice is dated November 16, 2026. The production privacy policy, data retention controls and Chrome Web Store disclosure will be finalized before public release. For development questions, use the TraceCue project issues page.
