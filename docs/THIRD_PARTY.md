# Third-party / reuse policy

TraceCue's initial code is newly authored for the current project and follows public Chrome API documentation. No code from GPL-licensed OpenJam has been copied.

- Chrome extension capture APIs: https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture
- Firebase AI Logic hybrid inference: https://firebase.google.com/docs/ai-logic/hybrid/web/get-started
- rrweb (MIT) can be evaluated as a later optional DOM replay layer: https://github.com/rrweb-io/rrweb
- Playwright's official test API and trace viewer can power later reviewed regression tests: https://playwright.dev/docs/trace-viewer

Before using any third-party code, verify the license and preserve required attribution. Prefer isolated dependencies over copying implementations; do not copy a commercial competitor's code.
